# Servidor Multiplayer do Dominó Azul

## Render
Crie um Web Service apontando para esta pasta/repositório.

Build Command:
npm install

Start Command:
npm start

Depois copie a URL HTTPS fornecida pelo Render e cole no campo "Servidor" dentro do APK.

O servidor aceita WebSockets/Socket.IO e mantém as salas em memória. É adequado para testes; ao reiniciar o serviço, salas abertas são perdidas.
